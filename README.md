# Квадратура — сайт

Одностраничный сайт для **Квадратуры** — магазина отделочных материалов в Таганроге:
напольные покрытия (кварцвинил, ламинат, линолеум, гибкий мрамор), обои,
натяжные потолки и жалюзи.

- Данные: карточка [2ГИС](https://2gis.ru/taganrog/firm/70000001114434506) —
  5,0 ★, 3 оценки, 3 отзыва, 17 фото, контакты, рубрики
- Статический сайт: HTML + CSS + JS, без сборки
- Стиль: «Сигнальный чертёж» (Unbounded + Manrope) — как у сайтов 01–08

## Особенности этой карточки

- Открытого прайса в 2ГИС нет (вкладка «Цены» пустая) — блок «Материалы и услуги»
  сделан карточками «витрина с образцами / бесплатно / под заказ», цены уточняются
  по телефону
- Ниша: полы (кварцвинил SPC, ламинат, линолеум, гибкий мрамор) + обои,
  натяжные потолки, жалюзи и подбор бригады укладчиков (из отзывов)
- Бесплатная доставка по Таганрогу и консультация — вынесены в факты и FAQ
  (оба подтверждаются отзывами)
- Фото: 3 фото из галереи 2ГИС (все 17 в карточке вертикальные — снимки витрин:
  кварцвинил Petra/marble, «ёлочка», стенд с ценами)
- Отзывы: на сайте все 3 отзыва 5★ (Мелания Мищенко, Ooo Ooo, Дарья Малащук);
  имена сверены по датам с вкладкой «Отзывы» — Малащук = отзыв от 23 мая
  («магазин на Александровской»), Ooo Ooo = от 25 мая («дали стенды домой»)
- Часы: ежедневно 10:00–17:00, без выходных
- Телефон в карточке один: +7 995 379-74-75; в контактах есть WhatsApp
  wa.me/79953797475 (тот же номер). VK/Telegram в карточке нет — кнопки не публикуются
- Адрес: Александровская улица, 67 (центр Таганрога); ориентир — Банковская
  площадь (2 мин, 250 м, 18 парковок)
- Оплата в карточке не указана — на сайт не вынесена
- Данные по рекламным блокам: посторонних tel-номеров в контактах не замечено

## Локальный запуск

    python -m http.server 8000

и открыть http://localhost:8000
